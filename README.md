# UI Prototype Experiment 10

## Project Description

This project is a UI prototype developed as part of Experiment 10.
The prototype demonstrates the design and functionality of the proposed user interface.

## Features

- User-friendly interface
- Responsive UI design
- Navigation between sections
- Interactive buttons
- Dark mode toggle
- Modern and simple design

## Technologies Used

- HTML
- CSS
- JavaScript
- Figma
- Git and GitHub

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, use VS Code Live Server to run the project.
